# Job Auto Apply

Портфолио-проект для поиска и предварительного отбора вакансий Junior Frontend (React/TypeScript, HTML/CSS) и отдельных фриланс-задач. Код собирает публичные объявления из нескольких источников, ранжирует их по заголовку, указанному стеку, уровню и совпадению с резюме, а затем отправляет отчёт в Telegram.

## Правила отбора

- Цель: Junior Frontend / React / TypeScript и вёрстка; вакансии «от 1 года» допускаются, если это явно указано в данных.
- Исключаются стажировки, Middle/Senior, Vue, Angular, Full Stack, React Native и Flutter.
- QA-объявления могут появляться в отчётах, но автоотклики QA приостановлены.
- Полные требования некоторых источников недоступны из выдачи; поэтому человек должен проверить оригинальную вакансию и текст перед отправкой. Ранжирование не является гарантией соответствия.

## Черновики и отчёты

Сопроводительное письмо составляется на основе подтверждённых личных проектов с прямой ссылкой на код. Оно не утверждает коммерческий опыт и не приписывает навыки, которых нет в портфолио. Для отправки требуется подтверждение черновика в Telegram; без него отклик не отправляется. Бот считает найденные, отобранные, пропущенные и отправленные объявления и сообщает причины в сводке. Полные тексты писем не публикуются в логах GitHub Actions.

## Количество откликов

Часовые и дневные ограничения количества отключены: `DAILY_JOB_LIMIT`, `DAILY_FREELANCE_LIMIT`, `HOURLY_JOB_LIMIT`, `HOURLY_FREELANCE_LIMIT` равны `0`. Пустое значение окружения по умолчанию также означает отсутствие лимита; положительное число снова включает соответствующую квоту. Проверка повторных откликов и подтверждение каждого черновика в Telegram сохраняются. Ожидание кнопки составляет пять минут; за один запуск доступны два неподтверждённых черновика, чтобы процесс успел завершиться в пределах времени GitHub Actions. Это отдельное ограничение ожидания, а не квота отправленных откликов.

## Запуск

`pip install -r requirements.txt`, затем `python worker.py`. GitHub Actions запускает поиск по расписанию в окне откликов (Asia/Yekaterinburg). Интеграции почты, Telegram и сайтов используют секреты окружения; их значения не должны попадать в репозиторий. Перед реальным использованием проверьте источники, фильтры, авторизацию и правила конкретной площадки.
